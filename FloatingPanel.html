FloatingPanel 🚀

通用浮动面板组件 — 可拖拽按钮 + 吸附侧边 + 滑动关闭 + 空闲透明度

快速使用

{/* 安装 React + ReactDOM 后 */}
<FloatingPanel
  buttonContent={<MiniIcon />}
  idleTimeout={2000}
  idleOpacity={0.45}
>
  <div style={{padding:20, color:'#cdd6f4'}}>
    弹窗内容
  </div>
</FloatingPanel>

Props

Prop类型默认值说明
buttonContentReactNode必填浮动按钮内容（缩略图）
childrenReactNode必填弹窗面板内容
buttonSizenumber46按钮尺寸
panelWidthnumber380弹窗最大宽度
panelMaxHeightstring'min(50vh, 420px)'弹窗最大高度 CSS 值
snapThresholdnumber10吸附触发距离(px)
swipeThresholdnumber60滑动关闭触发距离(px)
dragThresholdnumber5垂直拖拽记录阈值(px)
idleTimeoutnumber2000空闲透明度超时(ms)，0=禁用
idleOpacitynumber0.45空闲时透明度
onOpen()=>void-弹窗打开回调
onClose()=>void-弹窗关闭回调

交互规则

🎯 点击按钮 → 打开弹窗
🖱️ 拖拽按钮 → 自由移动
📌 拖到侧边 → 吸附/细竖杠
⬅️ 吸附后点击 → 打开弹窗
↔️ 弹窗水平滑 → 关闭+吸附
↕️ 弹窗垂直拖 → 保持新位置
🧊 闲置2秒 → 透明度45%
🎬 关闭弹窗 → 缩小复位右下角
